# QUISTER TECHNOLOGIES
### Engineering Digital Excellence · Independent Studio Architecture

QUISTER TECHNOLOGIES is an independent digital engineering studio combining thoughtful design, software architecture and modern technology to turn ambitious ideas into dependable digital products.

---

## 🏛️ Architecture & Platform Overview

- **Production Routes**:
  - `/` — Homepage: Interactive 3D Jellyfish hero, 60fps moving screenshot lanes, scroll-triggered Lenis card archive with realistic metallic hand guide, "What We Construct" engineering matrix, and precision 3D architectural ribbon lifecycle.
  - `/about` — Dedicated About page: 3D Champagne-Gold & Obsidian sculpture, studio origin story, operating principles, brand-colored interactive technology stack, verified team strength & 7-pillar technical expertise architecture, accessible FAQ accordion, and project inquiry CTA.
- **Global Page Transition Loader**:
  - Seamless full-screen transition overlay powered by GSAP across all genuine SPA route changes.
  - Features the official 3D metallic `Q` emblem, champagne-gold reflection sheen, segmented progress track, and tabular live percentage interpolation with safe watchdog guarantees.
  - In-page anchors scroll smoothly with Lenis without triggering full-screen loaders.
- **Unified Lenis Smooth Scroll Engine**:
  - High-precision inertia scrolling synchronized with GSAP ScrollTrigger ticker.
  - Live HUD telemetry showing section tracking, IST studio clock, and scroll progress.
- **Design Tokens**:
  - Primary Dark: `#09090E`, `#101016`
  - Warm Ivory: `#F3EFE8`, `#F8F5EF`
  - Champagne Gold: `#C9A466`, `#D9B978`
  - Deep Lavender / Purple Accents: `#7650B5`, `#B89AE5`
  - Typography: Instrument Serif, Cormorant Garamond, Manrope, IBM Plex Mono

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/abhay288/Quister-Technologies.git
cd Quister-Technologies

# Install dependencies
npm install

# Start development server
npm run dev

# Run Oxlint validation
npx oxlint src

# Production build
npm run build
```
